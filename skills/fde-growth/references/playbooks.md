# 打法与客户适配

以下为 FDE 实施设计，不是平台承诺的排名公式。

## SEO

| 路线 | 适用条件 | 实施资产 | 验证 |
|---|---|---|---|
| 技术 SEO | 页面难发现、迁站或重构 | URL/状态码清单、内链、规范页、sitemap、重定向 | 响应与正文、站长工具索引；模拟 User-Agent 不等于官方索引 |
| 高意图内容 | 买家比较、问价格、查方案 | 服务页、比较页、案例、费用条件、选型指南 | 非品牌查询、匹配页面、有效询盘 |
| 主题内容 | 决策链长 | 一个业务问题的主页面与支撑页面 | 缺口覆盖、内链、咨询问题变化 |
| 本地搜索 | 门店、餐饮、诊所 | 正确商家资料、地点页、照片、自愿评价入口 | 电话/路线/预约及实际到店 |
| 多语言 | 中韩或英语出海 | 本地买家语言、语言 URL 和地区说明 | 分语言查询及线索质量 |
| 程序化内容 | 有大量独立价值的真实数据 | 产品/规格页模板 | 小批索引与询盘通过后扩大；不做换地名的空页面 |
| 行业传播 | 有原创数据或技术经验 | 报告、演示、合作案例 | 相关引用、转介、询盘，不按购买外链数量验收 |

迁站保持重要 URL 或精确重定向、关键事实、内链与归因。技术选择依据真实渲染、可抓取性和维护成本，不单凭 CMS 名称。

## GEO

先选买家使用的平台、国家、语言。记录回答中的提及、推荐、引用和事实错误。将缺口分为检索缺口（无法访问/发现）、内容缺口（未回答问题）、证据缺口（只有自称优秀）、外部覆盖缺口（缺真实第三方资料）、事实冲突（地址/规格/身份不一致）。对应修复，避免一律加发文章。

单页可用：结论 → 适合/不适合谁 → 比较维度 → 证据与日期 → 条件 → 下一步。这是编辑选择，不是已证实的增长系数。

可查看 AI Mode 等产品的可见来源链接；它们不是内部完整 query fan-out。询问模型“为什么没有推荐我”得到的解释也不是排序机制证据。第三方覆盖应争取相关编辑报道、真实目录收录或授权案例，不购买伪装独立的排行榜。

## UGC

| 类型 | 价值 | 单独记录 |
|---|---|---|
| 自愿用户内容 | 真实体验与反馈 | 使用许可、原语境、撤回/到期约定 |
| 付费创作者素材 | 贴近用户表达的制作 | 交付、编辑、地区/期限、广告权、商业披露 |
| 达人/KOC 合作 | 素材与受众触达 | 发布账号、受众适配、自然/付费数据、赠品或佣金 |
| 员工/专家内容 | 专业解释与流程透明 | 明示身份、专业审核和商业关系 |

Brief 包含目标人群、真实场景、一个疑问、可展示证据、一个行动入口。一次优先测试钩子、证据表达或行动入口中的一个变量。3 个角度×2 个版本可作起步规模，不是固定配方。

可测试演示、使用过程、FAQ、合理比较、幕后、授权案例；在许可范围内复用到落地页、短视频和广告。付费放大另记广告费和付费触达，不能当纯自然增长。不同市场的广告资格与披露规则单独核实。

## FDE 客户起点

| 客户 | 待验证的问题 | 第一批资产 | 业务承接 |
|---|---|---|---|
| 韩国皮肤科→中文客户 | 资质、语言支持、流程信息不足 | 经审核中韩服务说明、资质出处、预约流程、费用条件、真实体验 | 咨询→人工确认→预约→到院 |
| 医美 Agency | 医院不清楚交付范围及价值 | 制作流程案例、样例、报价条件、合作 FAQ | 合格医院线索→需求会→方案→结算合同 |
| B2B 品牌/供应商 | 买家缺选型和交易条件 | 规格、MOQ/交期、样品流程、认证范围、技术比较 | 企业询盘→资格核实→样品/报价→订单回款 |
| 餐饮/门店 | 到访决策信息缺失 | 地点、菜单、价格条件、预约、真实体验 | 来源→预约→到店→自愿反馈 |
| 出海 SaaS/电商 | 比较与使用问题未回答 | 场景/替代方案页、演示、产品资料、案例 | 试用/加购→激活/付款→留存/退款 |

没有客户证据时上表只是待验证问题，不能声称客户已存在缺陷。

## 可销售的服务

诊断包交需求缺口、技术/承接检查与基线；试点包交有限主题/页面/素材实验及接单记录；持续包做有效实验扩展、更新、复用和复盘。按实施、运营、工具预算拆项，不卖保证推荐或包排名。先估客户容量与工时，再报价。
