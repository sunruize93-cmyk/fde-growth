# 测量约定

有效询盘由客户定义：目标人群/企业、真实需求、可联系、范围匹配。私信数不等于商机数。

## GEO 基线

可从 20–30 个买家问题、2 个引擎、分时段重复 3 次起步。这只是工作量建议，不保证统计功效；预算或权限不足时缩小并报告。API 与消费者网页端分开，不假定结果相同。

字段：question_id、问题、意图、来源、问题集版本、品牌/非品牌、平台/产品模式、可见模型版本（未知即未知）、语言、地区、时间、会话条件、是否搜索、运行状态、原回答证据位置、品牌提及、推荐语境、自有域引用、第三方引用 URL、事实错误及核查依据。

先冻结问题集再改内容；新增问题另成版本。登录失败不能算品牌未提及。按平台×语言×意图分层。

## 指标

- 请求成功率 = 有效回答数 / 尝试请求数。
- 品牌提及率 = 含正确品牌实体的回答数 / 有效回答数，排除同名误配。
- 正向推荐率 = 明确建议考虑/选择品牌的回答数 / 有效回答数；中性列举另记。
- 自有域引用率 = 至少引用一次获核实自有域的回答数 / 有效回答数。
- 搜索条件引用率 = 至少引用一次自有域的联网回答数 / 有效联网回答数。
- 事实错误率 = 含经核实错误的品牌回答数 / 可核查的品牌回答数；未知不自动记错。

分母为零记 N/A；报告分子、分母、范围和原始记录。无引用的有效回答进入无条件引用率分母。引用、推荐、点击是不同事件。

供应商 visibility、SOV、impressions 可能采用不同定义，保留原口径。Profound 的可见度以含至少一个品牌的回答为分母；Ahrefs 的估算曝光不等于访问。来源见 sources.md。

重复用于观察不稳定性，同一问题多次回答不是独立买家。统计比较以问题为聚类单位，分平台/语言，不夸大重复样本。未随机或建立可信对照，只报告观察变化。

## 连接业务

内容/活动有稳定 ID；保存 UTM、referrer、入口页和表单来源；平台私信使用允许的标记或人工记录。客户自报来源另存。没有 referrer 的直接访问不能自动归 GEO。

线索去重后记来源、首触与已知辅助触点、咨询时间、负责人、响应、资格确认、预约/演示、成交/回款、退款和未成交原因。不要为分析导出不必要的身份或医疗详情。

UGC 看有效素材比例、成本、相关互动和线索；SEO 看相关查询、点击和线索质量；GEO 看回答/引用及可归因流量。广告另记投入和转化，同一成交不能各渠道重复计算。

```text

观察期 / 销售周期 / 复盘日期：
投入上限（工时、内容、工具、广告分开）：
业务主指标 / 质量指标 / 渠道先行指标：
继续、调整、停止的预先标准：
发布/部署证据：
结果及其他解释（季节、促销、平台更新、容量）：

```

按基线和经济条件定门槛，不默认固定提升百分比。无业务数据时只验收准备程度。

新增贡献建议以成熟结算的可归因新增业务贡献，减新增制作、运营、广告、工具、履约、退款、接入成本；单位贡献已扣成本不再扣。工时节省与现金收益分开。前后比较不自动证明因果。
