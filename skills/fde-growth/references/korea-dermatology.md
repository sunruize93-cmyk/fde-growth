# 韩国皮肤科面向中国患者的 GEO 试点

核对日期为 2026-11-19。以首尔江南一家具备中文接待能力和外籍患者招揽登记的皮肤科机构为首期范围。中国大陆患者是需求方，韩国诊所是付费客户。按到访地区、出行安排和语言需求选题。

## 先做五个能拉开差距的动作

### 1. 从患者的筛选条件切入

把“韩国医美哪家好”拆成医生语言、全程口译、分院、周末、能否只面诊、费用组成、回国后联系等问题。首轮选诊所确实能兑现的两条需求，例如“江南周末中文面诊”和“飞回中国后有人跟进”。在固定题集看这些问题实际引用什么，后续从授权且匿名化的真实咨询补题。

先检查咨询、面诊、术后支持的中文服务是否分别成立。页面写明由医生、院内职员或预约口译提供，注明时段和需要提前预约的条件。只有部分环节具备中文支持时，逐项写清。分院单独维护时段与渠道。

### 2. 用韩文名打通政府目录与中文官网

给每家机构和每个分院建立事实表。逐字段保存法定韩文名、官方中文名、英文名、机构类型、地址、医生及专业资格状态、外籍患者招揽登记状态、语言安排、官方联系方式、核验日期、原始 URL 和负责人。中文别名只采用实际使用且经院方确认的写法，机构、分院和医生分别识别。

用同一张事实表核对官网、KHIDI 或属地可查的登记资料和符合资格的地区合作目录。三处已有记录不一致时让对应主体修正原件，保留前后依据。机构具备资格时可走江南区公开合作申请渠道。登记、合作机构身份、认证和专科医师是不同字段。中文页面按韩国法定机构类型和核实的专科资质表述。 [KHIDI 登记系统](https://www.medicalkorea.or.kr/korp/main.do) · [江南区合作资格](https://medicaltour.gangnam.go.kr/content/438/view.do?cid=438&lang=ko&mid=403-437) · [江南区申请入口](https://medicaltour.gangnam.go.kr/content/439/view.do?cid=439&lang=ko&mid=403-437) · [KHIDI 中文认证名单](https://www.medicalkorea.or.kr/cn/kahfAccreditedHospitals)

### 3. 给模型一张好读、能核对、能预约的页面

首批交付一张中文到访事实页和两张真正解决不同问题的问答页。每张页可用静态 HTML 或可靠的服务端渲染，带固定 URL 和正常站内链接。测试大陆正常网络上正文和预约入口能否打开，找中韩两侧各抽查一次。韩文原名、分院、登记范围、预约规则、复核日期以文字和来源链接出现，地图图标、二维码和证书照片辅助说明。能公开的费用用韩元、来源日期和适用条件解释，价格字段由诊所确认。

| 页面 brief | 上线验收 |
|---|---|
| 中文到访页。首屏呈现院名和分院、可用语言、时段条件与院方预约渠道。正文补上交通、改约规则和来源。 | HTML 可读，三语姓名与分院记录一致，使用虚拟预约标识与院方约定测试联系入口和回访闭环。 |
| 中文面诊与翻译 FAQ。分别回答谁提供翻译、能否只面诊、什么时候有中文服务。 | 每一条内容有院方负责人和复核日期，测试员从大陆能看懂并找到对应入口。 |
| 回国后如何联系院方。写明院方的可联系时段、复诊预约和问题转交路径。 | 院方人员验证承接流程，临床处置说明走院方流程。 |

可复用的素材是中韩双语的事实卡和到访步骤。先在官网发布获审内容，目录维护走官方申请。中文社媒先选一条审核允许的就诊流程说明，由具备对应资质和权限的发布方发。每个副本服务所在渠道并链接适用的原始来源。引用基线决定后续拓展渠道。

供院方填充的首屏草稿。方括号里的字段以已签认的事实替换，缺项时省略该主张。

> [官方中文名]（[法定韩文名]）[分院名]位于[地址]。目前可在[时段]使用[中文服务的实际环节]，由[医生、院内职员或口译人员]提供。若需[提前预约条件]，请在[官方入口]确认可预约时间。外籍患者招揽登记资料和院方联系信息于[日期]核对，见[官方来源]。

### 4. 逐段找出掉点

| 观察结果 | 工程判断 | 优先动作 |
|---|---|---|
| 官网给 URL 也读不到关键信息 | 可读性、网络或提取问题待判断 | 比较大陆浏览器、初始 HTML、DeepSeek Fetch 可读文本；核对服务器响应和站点自己的访问日志。 |
| 带院名可搜到，非品牌问题检索候选缺该院 | 对该类检索改写缺有效覆盖 | 看候选查询，补可证实的需求条件，修三语实体映射和目录记录。 |
| 候选有官网，但回答没引或引错分院 | 内容明确性或实体合并有问题待验证 | 检查被读段落，补分院标识、条件、更新日期和原始来源，再按同一题复测。 |
| 只有被问及院名时提到 | 品牌核实与非品牌发现的漏斗分开 | 查高意图中未出现的题，挑一类真实可兑现需求做少量改动。 |
| 已有真实引用但预约不通 | 承接漏失 | 测试已批准入口，修正大陆访问、中文值班、确认与跟进。 |

公开文档仅支撑诊断接口能力，具体原因有待对照验证。地址、医生和译员字段出错时优先更正，必要时暂缓放量。涉及个别源站的排查仅在公开界面或获授权账号与自有网站日志内做。

### 5. 用机构协作接住咨询

院方或具备相应资格的合作方承担所需的招揽、预约和临床接待。首期由院方管理咨询入口及记录，FDE 交付入口测试、标记与汇总报表。用页面或入口标识传递归因，不在公开提示词、共享表或来源 URL 里放护照、病历、面部照片、联系方式等个人资料。

把入口可达、咨询响应、预约确认、实际到院放进同一个漏斗。微信公众号或微信客服无法保留 referrer 时，用自报来源补充，保留未知。区分中文渠道总到院、已知 AI 来源到院、实验可能带来的新增到院。退款与取消纳入经营账。

## 30 天方案与验收

| 时段 | 交付 | 验收 |
|---|---|---|
| 第 1 周 | 一家诊所的事实表、两平台固定题基线、引用来源清单、院方入口测试 | 中国大陆测试员用固定消费者端获取回答。无法运行的记录原因。院方签认生效字段。 |
| 第 2 周 | 一张到访页和两张 FAQ，核对外部档案，安排审核及合法发布 | 真实浏览器可达，关键字段可读取，有条件的外部档案更新留下回执。 |
| 第 3 周 | 分批发布或复核，保持一组未改主题作观察参照 | 保存改动时间和已有指标。核对自然回答及引用，优先纠正分院、资质、语言和联系方式。 |
| 第 4 周 | 固定题复测与实际咨询/预约/到院汇总 | 提交分平台结果、各指标分子分母、有效咨询质量和下一步投资判断。 |

从 [24 条试题](../assets/korea-dermatology/prompts.csv) 启动。四条带院名的题先冻结替换值。探索和诊断题分开。首轮两平台各一次是最多 48 次，D0 与 D30 对同一套题各跑两轮则计划 192 次。预算紧时先跑每平台 8 条非品牌选院题，每个观察时点各跑 2 轮，共 64 次。使用新会话，固定产品模式和地区，跨时段轮换题目顺序。两次回答反映稳定性，同一题是统计单元。保持促销、网站及入境客流事件的记录。样本支持方向性判断，控制主题只提供参照。

- 取同一平台和同一组非品牌选院题作主比较。正确出现率的分子是正确提及目标分院的回答数，目标官网引用率的分子是至少有一条目标官网引用支持对应主张的回答数。两项均除以该组有效回答数。第三方支持引用、自报 AI 来源和品牌核实分别报。技术拦截与登录失败计入尝试成功率，相关题的出现情况记未知。
- 具备实际业务数据时，以院方确认有效咨询、预约和实际到院作为商业指标，记录中文响应和跟进容量。没有私域归因时保留未分配。对同一买家的多次触点去重。
- 约定扩张门槛后开始。建议至少两个不同非品牌问题在两轮里正确出现并有支持该主张的实际来源，且分院、资质、语言和官方入口等关键事实未发现新增严重错误。可继续扩大观察。投入扩大还应有真实咨询与承接质检数据。未满足时按掉点表定位和再测。

使用 [观测表](../assets/korea-dermatology/observations.csv) 记录产品、地区、模式、联网状态、是否存在引用、提及实体、证据是否支撑和原始回答位置。另用 [事实表](../assets/korea-dermatology/clinic-facts.csv) 记录韩文来源和中文页面的字段。

## 上线时核实的医疗业务边界

韩国《医疗海外进出及外籍患者招揽支援法》第 6 条涉及医疗机构和招揽业务主体的登记。区分客观信息、广告、接预约与介绍撮合，交由当地专业人员按实际链路判断。韩国《医疗法》第 56–57 条涉及医疗广告主体、内容与审查。KHIDI 对院方以折扣或其他请求换取公开治疗体验有专门提示。中国面向的发布还核对适用的医疗广告认定及平台规则，确认发布主体、渠道、内容和审查后再上线。首期素材集中于机构事实与到访流程。 [韩国医疗法](https://www.law.go.kr/LSW/lsSc.do?query=%EC%9D%98%EB%A3%8C%EB%B2%95) · [KHIDI 外籍患者常见问答](https://www.medicalkorea.or.kr/kmediwatch/board/faq) · [中国医疗广告认定指南](https://www.samr.gov.cn/ggjgs/tzgg/art/2025/art_fe4ab107d0784ee7afd212d16e6345e8.html) · [中国医疗广告监管指南](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/ggjgs/art/2025/art_cd56662cf13b4ad59eabfe31cb1122e1.html)
